ClientClient - Fabric client mod for Minecraft 1.21.11

BUILD ON GITHUB
1. Extract this ZIP on your computer.
2. Create an empty GitHub repository.
3. Upload the CONTENTS of this extracted folder to the repository root.
   Do not upload this ZIP as a single file.
4. Confirm that the repository shows these paths at its top level:
      build.gradle
      settings.gradle
      gradle.properties
      src/
      .github/workflows/build.yml
5. Open the Actions tab. The workflow starts after the first commit/push.
6. Open the successful run and download the artifact named
   ClientClient-Minecraft-1.21.11. Extract it to get the mod JAR.

The mod is for Fabric Loader and Minecraft Java Edition 1.21.11.
Use a matching Fabric API version in the mods folder as well.

MENU
Press Right Shift to open the menu by default. The menu key can be changed
in the menu settings.
